Router setup

Set the destination to this application's reachable IPv4 address, then enable Traffic Flow on the router:

/ip traffic-flow set enabled=yes interfaces=all
/ip traffic-flow target add dst-address=<SERVER_IP> port={{ flow_port }} version=9

The packet source must match this router's host or its configured exporter source IPv4. Allow UDP {{ flow_port }} from that router to this server.
